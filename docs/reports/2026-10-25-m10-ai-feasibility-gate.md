## 2. Gate Findings & Architecture Decision

1. **Local Host State**:
   - The development laptop host currently does not have the `ollama` CLI installed in PATH.
   - Downloading multi-gigabyte models during automated builds or offline demonstrations without pre-seeded binaries violates deterministic CI test execution.
2. **On-Device Mobile State**:
   - Compiling native llama.cpp / ExecuTorch C++ libraries into the Expo SDK 58 React Native application adds significant bundle weight (>1.5 GB), native linking fragility across Expo updates, and severe thermal throttling risks on mid-range Android hardware.
3. **Primary Recommendation**:
   - Implement an extensible **Multi-Provider Gateway Architecture**:
     - `LocalGatewayAiProvider`: Capable of communicating with a loopback/LAN Ollama service via bearer pairing token when available.
     - `MockAiProvider`: Available for deterministic testing and regression evaluation.
     - `DeterministicTemplateProvider`: Complete, zero-cost, instant (<5ms), zero-hallucination structured brief generator that strictly satisfies `JobBriefDraftSchema` and requires no external network or API keys.
4. **Honest Provenance & Attribution**:
   - The UI strictly differentiates between model-generated text and deterministic templates:
     - When generated by an AI model: Labeled `AI Draft — Generated by [Model]` with a mandatory human review disclaimer.
     - When generated by the rule-based engine: Labeled `Manual Template Draft — Generated Deterministically`.
     - Deterministic templates are NEVER mislabeled or presented as AI inference.
5. **Prompt Injection & Safety Defenses**:
   - All free-text inputs from users are treated as untrusted data and enclosed in boundary tags.
   - Output sanitizer strips `<script>`, HTML tags, markdown execution artifacts, and SQL syntax.
   - Authoritative facts (category, work mode, budget, public area) cannot be overridden by model hallucinations.
